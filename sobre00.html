Sobre o Pedro

Pedro atua em uma equipe de banco de dados de um Network Operations Center (NOC), onde gerencia a infraestrutura de sistemas corporativos e a administração multiplataforma de bancos de dados — incluindo a rotina de ligar pluggable databases e gerenciar esquemas como o faturamentosdb.

Como comecei e Hardware

Sua trajetória envolve muito trabalho prático, não se limitando apenas a software. Pedro realiza modificações físicas e troubleshooting avançado em GPUs e placas-mãe de impressoras 3D (reconhecendo rapidamente os dispositivos de diagnóstico na placa). Ele também domina testes de conectividade local e avaliações de segurança de rede sem fio.

No que estou trabalhando

Além das operações corporativas e dos estudos para a certificação Oracle Database Administration I, Pedro desenvolve diversos projetos próprios:

  • Automação Local de IA — Arquitetura utilizando n8n, webhooks e interfaces locais de LLM para integrar inteligência artificial aos workspaces de produtividade.
  • Desenvolvimento Web — Programação de extensões funcionais para o Google Chrome e criação de jogos web customizados (estrelando uma toupeira autêntica no design).
  • Emulação Retrô — Configuração intensiva de firmwares no console Trimui Smart Pro rodando CrossMix-OS, ajustes no PortMaster e setup do PokeMMO.
  • Design Gráfico — Criação de modificações gráficas personalizadas, como camisetas escolares com emblemas específicos.

Objetivos

Objetivo de curto prazo — Avançar nas competências e arquitetura core para o exame Oracle DBA I, além de gerenciar a logística de suas viagens programadas (seja o planejamento cuidadoso para o Canadá ou o roteiro de São Paulo para Foz do Iguaçu).
